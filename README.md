# 📊 Stock Portfolio Tracker

My second Python project! A simple calculator that shows the total value of your stock investments.

---

## ✨ What It Does

- Accepts stock ticker codes (AAPL, TSLA) or full company names (Apple, Tesla)
- Calculates total value based on shares you own
- Checks multiple stocks in one session
- Shows your total portfolio value
- Saves results to a text file

## 🚀 How to Run

1. Install Python 3
2. Open terminal in the project folder
3. Run: `python stock_portfolio.py`
